# Fairy Ring Pinball (TIC-80)

Pinball game for TIC-80 1.3.1 (Lua, 240x136, 60fps).

## Folders
- **This folder** (`C:\Users\kwhyc\Workspace\pinball-muliscreen`): research and background.
  - `research/` - reference games (Revenge of the Gator, Kirby's Pinball Land, Pokemon Pinball, Terra Nova PICO-8, etc.), `links.txt`, subgenres PDF.
  - `table-ideas/` - table concepts (0xFae Pinball, 1941 Pinball).
  - `tic80 build/` - snapshots/backups and the TIC-80 v1.3 Windows exe.
- **TIC-80 folder** (`C:\Users\kwhyc\AppData\Roaming\com.nesbox.tic\TIC-80`): live working copy that TIC-80 loads directly.
  - `pinball.tic` - the cart. `phase0.lua` - current game code. `fairy_sprites.png` - sprite sheet.
  - Edit the live code here so it can be loaded straight into TIC-80.
